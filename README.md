# Task Manager

A modern task management application built with React, Vite, Tailwind CSS v4, and shadcn/ui.

## ✨ Features

- Add and remove tasks
- Mark tasks as completed
- Search tasks
- Filter tasks (All, Active, Completed)
- Dark / Light mode
- Local Storage persistence
- Responsive UI

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS v4
- shadcn/ui
- React Hooks

## 🪝 Hooks Used

- useState
- useEffect
- useMemo
- useCallback

## 🚀 Getting Started

```bash
pnpm install
pnpm dev
```

## 📦 Build

```bash
pnpm build
```
